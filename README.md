# Бюро решений

Статический сайт с контентом из [макета Figma «Саблина Ника»](https://www.figma.com/design/APaW5kcEMKzPKhunkZ9Bll/?node-id=0-1). HTML, CSS и JavaScript без сборки и серверных зависимостей.

Новый дизайн следует выбранным пользователем референсам: белый фон, графитовая типографика, красные акценты, крупные выразительные заголовки и спокойный основной текст. Общая сетка и типографика применены ко всем страницам; содержание услуг, тарифы, отзывы и контакты сохранены.

Сайт: https://n6ssa.github.io/decision_bureau/

## Страницы

Основной сайт — единый лендинг: первый экран, факты о компании, преимущества, услуги для юридических и физических лиц, раскрывающиеся тарифы, калькулятор, отзывы и контакты. Меню прокручивает страницу к разделам, не перезагружая формы.

Преимущества раскрываются при наведении, а нажатием можно закрепить текст открытым. На сенсорном экране и с клавиатуры работают кнопки; Escape закрывает выбранный пункт. Анимация учитывает системную настройку уменьшения движения.

Подробные описания 12 услуг доступны отдельно по ссылкам из лендинга. Навигация через hash сохраняет прямые ссылки и историю браузера на GitHub Pages, в том числе под базовым путём `/decision_bureau/`.

Основные шаблоны и поведение находятся в `script.js`, дополнительные страницы услуг — в `service-pages.js`, оформление — в `style.css`. Локальная графика из Figma находится в `assets/`, соответствие имён слоёв файлам — в `assets/design-assets.json` и `design-assets.js`. Временные ссылки Figma не используются при просмотре сайта.

## Просмотр и проверки

Требуется Node.js 22 или новее:

```sh
node scripts/serve.mjs
node scripts/check.mjs
```

Предпросмотр: http://127.0.0.1:4173/decision_bureau/

Проверка контролирует рендер всех страниц, внутренние ссылки, локальные файлы, повторяющиеся идентификаторы, экранирование текста и граничные значения калькулятора.

Для браузерной проверки нужен Playwright 1.57.0, доступный Node.js, и Microsoft Edge. Можно установить только инструмент проверки, не меняя зависимости сайта:

```sh
npm install --no-save --package-lock=false playwright@1.57.0
node scripts/browser-check.mjs
```

Сначала запустите сервер предпросмотра. Скрипт проверяет 21 страницу при ширине 1280, 768, 390 и 320 пикселей, загрузку графики и шрифтов, выход текста за карточки, горизонтальное переполнение, формы, калькулятор и историю браузера. Скриншоты сохраняются во временный каталог системы `decision-bureau-qa`.

Переменные `BROWSER_EXECUTABLE` и `SITE_URL` позволяют выбрать другой установленный Chromium-браузер и адрес проверяемого сайта.

## Формы и калькулятор

Формы проверяют обязательные поля и подготавливают письмо на `buroresh01@mail.ru`. Пользователь открывает и отправляет его в почтовом приложении. Серверной отправки и хранения заявок нет; сайт прямо сообщает, что письмо ещё не отправлено.

Макет содержит пример суммы 5234 ₽, но не содержит правил расчёта. Поэтому калькулятор использует явно обозначенную демонстрационную формулу. Для коммерческого расчёта нужно заменить `calculateCost` утверждёнными правилами.

Ставки тарифов, контакты и тексты перенесены из макета. Два последних тарифа имеют одинаковое название «Расчет заработной платы», как в оригинале. Для других городов макет не содержит адресов; на странице контактов указан московский офис.

## Публикация

При push в `main` GitHub Actions выполняет `scripts/check.mjs` и публикует только HTML, CSS, JavaScript, favicon и папку `assets/`. Исходники проверок и локальный сервер в опубликованный сайт не попадают.

Источник Pages: **Settings → Pages → Source → GitHub Actions**.
