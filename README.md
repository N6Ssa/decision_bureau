# СХОДИТСЯ

Минималистичный сайт компании по сопровождению 1С. Статический HTML, CSS и JavaScript без сборки.

## Публикация

GitHub Actions публикует сайт при push в `main`. Адрес: https://n6ssa.github.io/decision_bureau/.
Если Pages ещё не включён: Settings → Pages → Source → GitHub Actions.

## Локальный просмотр

Откройте `index.html` в браузере или запустите любой статический HTTP-сервер в корне проекта.

## Перед коммерческим запуском

Тарифы и контакты — демонстрационные. Замените их реальными данными. Форма проверяет обязательные поля и показывает демонстрационное окно; заявки не отправляются и не сохраняются. Для приёма заявок требуется подключить обработчик и добавить необходимые документы по обработке персональных данных.

## Калькулятор сопровождения 1С

Условные ставки: 2 часа — 5 000 ₽, 6 часов — 12 000 ₽, 12 часов — 22 000 ₽ в месяц на одну базу. Доплата за конфигурацию: бухгалтерия — 0 ₽, зарплата — 2 000 ₽, торговля — 3 000 ₽. До 3 пользователей включено, каждый следующий — 500 ₽. Другая или доработанная конфигурация требует индивидуальной оценки. Лицензии, подписки, сервисы и дополнительные часы не включены. Это демонстрационная модель, а не реальные тарифы.
